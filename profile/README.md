**Bloxa** is a component library you install with one command and keep in your own codebase.

```bash
npx bloxa add button
```

- **Free** — core components and motion presets.
- **Pro** — production-ready blocks and page templates, one-time purchase, lifetime access.

> 🇹🇷 Bloxa, React ve Next.js için hareket odaklı arayüz blokları sunar. Türkçe dokümantasyon ilk günden hazır.
